# Ted recovery-led landing experiment

This is a standalone design experiment. It is not imported by `src/app`, does not create a Next.js route, and cannot change the live landing page.

Preview it locally:

```bash
python3 -m http.server 4173 --directory design-experiments/ted-recovery-led
```

Then open `http://localhost:4173`.

The contact email is intentionally not invented. Add a verified public email before considering any part of this experiment for production.
